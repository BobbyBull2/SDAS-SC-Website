# SDAS Fleet Terminal – Preview Branch

This branch is reserved for the Fleet Terminal prototype and is **not** the live website deployment.

The interactive v2.1 preview includes the approved SDAS astronaut recliner banner, a 3-option welcome screen, My Hangar, an organization fleet registry, pilot directory, image uploads, editable loadouts and browser-local storage.

This branch currently contains preview notes only; the HTML and image assets still need to be uploaded here to make an online preview. Do not merge into main or change the production Pages deployment until approved.
